⬇ Hent ordpresse.zip

📱 Sådan installeres ordbogen i KOReader:

  1. Pak ordpresse.zip ud på din computer el. e-læser.
  2. Kopier mappen ordpresse/ ind i koreader/data/dict/ på din Kindle, Kobo el. Android e-reader.
  3. Genstart KOReader: Luk og genstart KOReader (eller genstart enheden), så de nye ordbogsfiler indekseres.
  4. Åbn KOReader > Ordbogsindstillinger > Vælg Den Danske Ordpresse som primær ordbog.
